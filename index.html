Flight tracking · Streaming & ELT

OpenSky Observatory

A worldwide aircraft-data pipeline with live Grafana dashboards for 20 major airlines. Reliable ingestion, incremental analytics, and pipeline monitoring turn OpenSky positions into an observable data platform.

  • Python
  • Apache Kafka
  • PostgreSQL
  • dbt
  • Grafana
  • Docker Compose
What I built · technical details+
OpenSky→Kafka→Python→PostgreSQL→dbt→Grafana
  • Built a Python ingestion pipeline for worldwide OpenSky aircraft positions, with Kafka buffering, record validation, and quarantine of invalid messages for inspection.
  • Implemented an idempotent PostgreSQL sink: deduplicated aircraft-position observations, protected current state from out-of-order messages, and committed Kafka offsets only after an atomic database transaction.
  • Developed incremental dbt models for aircraft, airlines, and activity analytics, including late-committing observations and retention cleanup. Live traffic panels query current and raw tables directly, independently of the five-minute dbt build cycle.
  • Provisioned Grafana dashboards for recent positions across 20 selected major airlines and worldwide pipeline health: freshness, latency, throughput, and API credits. Dashboards show live OpenSky data only; counts represent observations, not fleet sizes or completed flights.
  • Containerized the stack with Docker Compose and added Python/dbt validation, GitHub Actions CI, and Kafka/PostgreSQL integration tests covering forced rollback and replay. A synthetic source supports offline and CI testing.
